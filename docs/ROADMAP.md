# Roadmap

このサイトの目的・現状・今後の方針をまとめた長期視点のドキュメント。
細かい実装タスクは [backlog.md](./backlog.md) を参照（`/sy-next-task` はそちらだけを読む）。

---

## 目的

SF6 のコンボを **YouTubeタイムスタンプ付きで整理・共有・投票** できる Wiki 型サイト。

- 個人の練習メモを永続化する（personal）
- 良いコンボは公開して他人と共有する（shared）
- 他人のコンボを自分用に派生させる（fork）
- 「現バージョンで成立しないコンボ」をコミュニティで識別する
- 〆方法ごとに **起き攻め** を自動でサジェストしつつ、ルート個別の手動上書きを許す
  （同じ〆技でも、繋ぎや距離・高さでフレーム状況や使える重ねが変わるため）

データは [`sf6-combo-archiver`](../../sf6-combo-archiver) パイプラインが Supabase に投入する
（同一 Supabase プロジェクトを共有）。本サイトは表示と投票のみを担う。

### Phase 2 — 仕様確定とスキーマ設計（進行中: 仕様詰め）
モックで詰めた論点を「採用 / 不採用 / 保留」で確定し、Supabase スキーマに落とす。
`sf6-combo-archiver` 側にも影響するので、archiver と歩調を合わせる必要がある。

決まったこと（2026-05-23）:
- **オーナーシップ**: `combos` / `okizeme` を同一テーブルで保持し、`owner_id` + `visibility(private/unlisted/public)` + `forked_from` を持つ。
  公開／非公開は visibility の切替で済ませ、fork は同テーブル内の複製で派生関係を保つ。

決まったこと（2026-05-25）:
- **サイトの3軸構成**:
  1. **世界全体（`/explore/[character]`）** — 公開コンボの読み取り専用ビュー。D&D / 追加 / 順序変更は不可。
     ユーザー操作として許すのは「自分用にfork」「投票（Good/Bad/現ver不可）」「絞り込み」のみ。
  2. **自分用（`/character/[name]`）** — 個人のコンボ・起き攻め一覧。D&D での並び替え、追加、編集可。
     ここで作成したコンボを「アップロード」操作で `/explore` に公開する（= visibility を public にする）。
  3. **詳細（`/combo/[id]`）** — コンボ単体の詳細・動画埋め込み・投票。
- **`/explore` の表示順（グローバル設定）**: ユーザー個別の並び替えは持たず、サイト全体で決まる。
  - 外側: ~~〆分類（大分類 → 小分類）でグルーピング~~ → ~~2026-10-23 に始動技でグルーピング~~ → 2026-11-02 に **状況別** へ変更（下記）
  - 内側: ユーザーがビュー切替できる（**優先度順（既定。2026-11-02 に追加）/ 投票スコア順 / ダメージ降順 / 新着順**）
- **ノート**（旧称プレイリスト）: コンボノートと起き攻めノートを別系統として持つ。
  1ノートは1種類のアイテムのみを順序付きで束ねる。例: 「中央 SA2〆ノート」「対モダン用ノート」。
  URL は `/me/notes/combos/[id]` / `/me/notes/okizeme/[id]`。
  ※「コンボとその起き攻めをセットで束ねる」用途は、コンボ詳細の〆分類経由で自動紐付け表示されるため、ノート側では持たない。
- **コンボ一覧の起き攻め展開**: `/[character]` のコンボ一覧で、各行に起き攻め展開トグル（▶）を置く。
  クリックでその行の〆分類に紐付く起き攻めをインライン展開する。
- **用語**: 「プレイリスト」は不使用。研究記録の単位として「ノート」を採用。

決まったこと（2026-10-23）: モック UI の見直し（使いづらさの洗い出しから。タスクは backlog「モック / UI」）
- **一覧の分け方**: 見出しは **始動技の1段**（2MK / 5HK / j.HK / インパクト …）。
  位置（中央/端）・ヒット状態（CH/PC）・ゲージは、行のバッジと絞り込みチップに回す。
  自由入力の大分類/小分類（categoryMajor / categoryMinor）と、その名前変更・追加・削除は廃止する。`/explore` も同じ分け方にする。
  （見出しを始動技にする部分と、位置を行のバッジに回す部分は、2026-11-02 に状況別へ変えた。大分類/小分類の廃止はそのまま）
- **一覧の行**: コマンドを主役にし、コンボ名はその下に小さく薄く出す。
  コンボ名に分類・位置・〆を書かない（それぞれ見出し・バッジ・〆の列に任せる）。
  （コンボ名を下の行に出す部分は、2026-11-03 にコマンドの後ろに続ける形へ変えた。下記）
- **分岐コンボの入力**: ルートを1本ずつ最後まで書き、共通部分は自動でまとめてツリーにする（トークンをクリックして分岐させる方式はやめる）。
- **コンボ詳細**: 動画の横にルート一覧を置き、選んだルートのコマンド・投票・起き攻めを下に出す。
- **起き攻めの紐付け**: 〆分類で紐付ける。〆が違っても有利フレームが同じ起き攻めは「参考」として薄く出す
  （有利フレームだけで紐付けると、距離の違う〆の択まで混ざるため）。
- 「練習で使う」場面（ノート・習得状況など）は、今は困っていないので新しいタスクにしない。

決まったこと（2026-11-02）: コンボの表記と一覧の分け方
- **表記**: doskonnbu の動画の字幕のような文字表記（`2中P > 弱K > 弱スパイク`）を既定にし、チップ表示は選択式で残す。
- **一覧の行**: 余程長いコンボでない限り、コマンドは1行に収める。
- **一覧の分け方（見直し）**: 始動技の1段をやめて、状況別にする。`/explore` も同じ。
  - 大見出しは 中央 / 端 / インパクト / スタン / イウサール（動画の章立てと同じ）。
  - 中央・端の下は場面: 通常 / ラッシュ / 飛び / カウンター・確反。項目は足さず、始動技とヒット状態から自動で決める。
  - 位置「どこでも」はインパクト・スタン・イウサールだけに残す（位置を問わないコンボなのは事実）。それ以外は中央か端に決める。
  - 始動技はコマンドの先頭で読めるので、絞り込みの `<select>` として残す。位置は見出しで分かるので、行のバッジや絞り込みチップには回さない。
- **コンボの優先度**: 各コンボに、実戦で使う頻度を3段階（よく使う / ときどき / あまり使わない）で付ける。
  - コンボの属性として持ち、キャラハブと `/explore` の両方に出す。エディタで変えられ、fork でコピーする。
  - 取り込み分の初期値は動画の補足から決める（根拠が無ければ「ときどき」）。
  - 一覧では見出しの中の並び順・行のバッジ・絞り込みチップに使い、「あまり使わない」は最初は畳む。
- **一覧の行の形**: コマンドを1行に収めることを優先し、列を増やさない。`/explore` も同じ形。
  - 公開一覧の投稿者は列をやめて、キャラハブと同じくコマンドの下に出す（2026-11-03 からはコマンドの後ろ）。
  - ヒット状態（CH/PC）のバッジは専用の列にせず、該当する行だけコマンドの左に出す（全部「カウンター・確反」の見出しに入るので、同じ見出しの中で左端がそろう）。
  - コンボ名と優先度は列表示で隠せるので、詳細へのリンクはコマンド自体に、分岐の ▶ はコマンドの段に置く。

決まったこと（2026-11-03）: 一覧の行の高さと絞り込み
- **行の高さを抑える**（1画面に多く見せたい）: 優先度・出典・コンボ名・状況タグは下の行に出さず、コマンドの後ろに同じ行で続ける。収まらない長いコマンドの行だけ下に回す。行間の挿入用のすき間もなくす（境目にマウスを乗せたときだけボタンを重ねて出す）。`/explore` も同じ。
- **ゲージの絞り込み**: ラッシュ（DR・CR）を使うコンボは OD に入れる（「ノーゲージ」はDゲージも SA も使わないこと）。分岐コンボはどれか1つのルートが合えば出し、開いたときは合わないルートを薄く出す。

### モバイル対応（かなり後回し）
現状の UI は PC ファースト（コンボ一覧が 8カラムテーブル等）でスマホでは破綻する。
ただし当面の優先度は低い：本サイトの読者層は PC でフレームデータや動画を見ながら使う想定が中心。
着手する場合の指針：

- 一覧テーブルはモバイルでカード化（または重要カラムだけ `hidden md:table-cell` で残す）
- コマンドノーテーションは横スクロール許容
- 投票・編集UI のタップ領域確保
- Phase 5（全キャラ展開）完了後、利用ログを見て着手判断
