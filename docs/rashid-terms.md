# Rashid 技名 ↔ コマンド対応表

archiver が doskonnbu の動画字幕から取り込んだ日本語レシピ（`../sf6-combo-archiver/data/rashid/*.json` の `recipe_ja`）を、
テンキー記法のコマンドに変換するための辞書。取り込みスクリプト（backlog「archiver の Rashid データを…」）がこの表を読む。

出典: [公式コマンドリスト](https://www.streetfighter.com/6/ja-jp/character/rashid/movelist)（2026-10-21 取得）。コマンドは 1P 側（右向き）のテンキー表記。

## 直し方

- **見るのは確度が ○ と △ の行だけ**。「コマンド」列が間違っていれば書き換え、確認したら「確認」列に `✓` を入れる
- 確定として扱われるのは、**確度 ◎ の行**と、**`✓` が入った行**。○ / △ で `✓` の無い行は未確定（取り込み時に変換せず日本語のまま残す）
- 「確度」は Claude が下書きした時点の自信。書き換えなくてよい
  - ◎ 公式コマンドリストで確認済み（`✓` 不要）
  - ○ 公式の技は確定しているが、動画の呼び方がその技を指すかは推測
  - △ 推測
- ◎ の行で誤りに気づいたら、コマンドを直して `✓` を入れればよい
- 行の追加・削除は自由。列の順番は変えないこと（スクリプトが列位置で読む）
- コマンドの書き方は [src/mock-data/rashid.ts](../src/mock-data/rashid.ts) の `RASHID_PALETTE` に合わせる（例: `5MP` `2MK` `j.HK` `214LK` `236PP`）
- 表を直したら `npm run import:archiver` で取り込み結果（src/mock-data/rashid-archiver.ts）を作り直す
- 出現数 = 2本の動画（コンボ20選・セットプレイ10選）のレシピに出てきた回数。0 は解説字幕だけに出てきた語
